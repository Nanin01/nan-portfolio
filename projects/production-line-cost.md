# 📊 Production Line Cost

## Overview

A production line cost control system developed to monitor labor costs, expenses, and scrap across production lines.

## Business Problem

Existing cost information was not fully utilized for real-time operational analysis and decision-making.

## Solution

Developed a web-based cost control system that transforms production cost data into actionable information for production leaders.

## Key Features

* Labor cost monitoring
* Production expense tracking
* Scrap cost monitoring
* Production line analysis
* Real-time dashboards
* Cost reports
* Data visualization

# 🔧 Compressor Rework Management

## Overview

A system developed to control and track compressor rework processes and support root cause analysis by rework category.

## Business Problem

Rework information needed to be monitored and analyzed to identify recurring issues and improve production processes.

## Solution

Developed a rework management system with real-time dashboards and analytical reports to support production monitoring and management decision-making.

## Key Features

* Rework process tracking
* Rework category management
* Root cause analysis support
* Real-time rework dashboard
* Daily analysis
* Monthly analysis
* Yearly analysis
* Management reporting

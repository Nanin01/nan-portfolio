# 🛡️ Safety Inspection System

## Overview

A web-based fire extinguisher inspection system using QR Codes to support safety inspection activities.

## Business Problem

Safety inspections needed reliable tracking to ensure that required inspections were completed and properly recorded.

## Solution

Developed a QR Code-based inspection system that allows employees to perform inspections using personal mobile devices or company scanners.

## Key Features

* QR Code identification
* Fire extinguisher inspection
* Mobile-friendly inspection process
* Inspection status tracking
* Inspection history
* Reporting dashboard
* Missed inspection monitoring

# 🔄 Engineering Change Request (ECR)

## Overview

A web-based ECR management system developed to support multi-department engineering change workflows.

## Business Problem

Paper-based approval processes could result in document delays, document loss, and limited visibility of approval status.

## Solution

Developed an online ECR workflow and approval system to manage engineering change requests across multiple departments.

## Key Features

* ECR creation
* Multi-department workflow
* Online approval
* Approval status tracking
* Large file attachments
* Document management
* Workflow monitoring

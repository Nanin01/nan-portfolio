# 🔔 Follow Up System

## Overview

webSite developed to track tasks and documents across departments with real-time status updates.

## Business Problem

Manual follow-up processes made it difficult to monitor document status and identify overdue tasks, which could result in delays between departments.

## Solution

Developed a centralized webSite follow-up system that allows users to monitor task and document status in real time.

## Key Features

* Task tracking
* Document tracking
* Real-time status updates
* Due date monitoring
* Overdue status tracking
* Automatic email notifications
* Cross-department follow-up
